# OS_Conf

# Описание работы.
Скрипт проверяет, какая операционная система стоит на компьютере (Windows, Linux или macOS), собирает основные характеристики компьютера и сохраняет их в файл result.json.

# Выводимые данные.
1. Информация об ОС: название операционной системы, версия релиза, подробный номер сборки, разрядность и архитектура;
2. Аппаратные данные: модель процессора, количество доступных вычислительных ядер(потоков);
3. Окружение: сетевое имя ПК, имя учетной записи пользователя;
4. Интерпретатор: текущая версия Python.

# Используемые модули.
Для выполнения выбраны только стандартные модули Python:
1. Модуль platform;
2. Модуль os;
3. Модуль getpass;
4. Модуль socket;
5. Модуль json.

# Используемые функции и их назначение.
1. platform.system(), platform.release(), platform.version() и platform.architecture() дают базовые сведения об операционной системе;
2. platform.win32_ver(), platform.mac_ver(), platform.libc_ver() вызываются в зависимости от ОС и дают более расширенные сведения об ОС;
3. platform.machine(), platform.processor(), os.cpu_count() извлекают данные об аппаратном обеспечении;
4. socket.gethostname() определяет имя хоста/домена компьютера;
5. getpass.getuser() определяет имя текущего активного пользователя;
6. platform.python_version(), platform.python_compiler() определяют версию питона, название компилятора и его версию;
7. json.dump() записывает словарь в файл, формата json, в кодировке UTF-8 с отступами.
